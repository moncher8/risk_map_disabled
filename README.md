## 🌐 Risk Map (Disabled Population)

서울시 공공데이터를 활용해 **장애인 인구 분포와 폭염 취약 지역을 한눈에 볼 수 있도록 만든 웹 지도**입니다.  
2025 **서울시 데이터 허브 시각화 공모전**에 제출했던 작품입니다.

- **프로젝트 개요**
  - 서울시 장애인 등록 인구 분포를 행정동 단위로 시각화
  - 폭염에 특히 취약한 지역/시설을 지도 위에 함께 표시
  - 지도를 통해 취약 지역을 직관적으로 파악하고, 복지·안전 정책 수립에 참고할 수 있도록 기획

- **미리보기 (Preview)**
  - 행정동별 장애인 인구 규모 표현
  - 폭염 취약 시설, 무더위 쉼터 등 주요 지점을 마커로 표시
  - 마우스 오버/클릭 시 해당 지역의 상세 정보(인구, 시설 수 등) 팝업 제공
